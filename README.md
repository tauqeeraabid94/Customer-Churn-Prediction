# Customer Churn Prediction Project

## Project Overview

This project is based on Customer Churn Prediction using Python and Machine Learning.

The goal of this project is to predict whether a customer will leave the company or stay based on customer data.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

---

## Machine Learning Model

* Logistic Regression

---

## Project Steps

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Data Visualization
6. Model Training
7. Model Evaluation
8. Accuracy Prediction

---

## Project Outcome

The model was trained successfully and achieved good prediction accuracy for customer churn analysis.
